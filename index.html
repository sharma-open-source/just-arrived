About Just Arrived

Just Arrived is a free GitHub Trending alternative that catches rising repositories earlier — while they're still gaining momentum, not after they've already peaked. It scans the GitHub Search API live in your browser and ranks results by a growth-velocity score, so you can find hidden gems and about-to-trend projects days or weeks before they show up on the official Trending page.

Filter by language, age window (7–90 days), and minimum stars, then sort by trend score, star velocity, or forks. No account, no backend, no tracking — your optional GitHub token (for a higher API rate limit) stays in your browser's localStorage only.

Data: GitHub Search API, auto-refreshed every ~30 min · score = ★/day × 0.5 + forks/day × 0.2 + push-freshness × 0.2 + community × 0.1 · 📡 RSS feed · built with Claude Code

🔑 GitHub token (optional)

Without a token the GitHub Search API allows 10 requests/min. Paste a fine-grained personal access token (no scopes needed — public read only) to raise the limit to 30/min. It is stored only in your browser's localStorage.
